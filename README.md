# Vice City Coffee — одностраничный сайт

Чистые HTML/CSS/JS, без сборщика и зависимостей. Шрифты (Unbounded, Golos Text) подтягиваются с Google Fonts.

## Запуск
```bash
cd vice-city-coffee
python3 -m http.server 8000
# открыть http://localhost:8000
```
(Нужен именно сервер, а не двойной клик по index.html: меню грузится из `menu.json`.)

## Что заполнить руками
- **Цены и названия:** `menu.csv` (колонки: Название; Цена, ₽; Объём/вес; Файл картинки). После правки таблицы выполните пересборку (ниже). Итоговые данные сайта лежат в `menu.json`, его тоже можно править напрямую.
- **Адрес, часы, телефон:** блок `#find` в `index.html` (заглушки в квадратных скобках).
- **Соцсети:** ссылки в футере `index.html`.
- **Карта:** в `#find` схема-заглушка (SVG); при желании замените на свою.

## Пересборка меню
```bash
pip install pillow numpy scipy opencv-python
python3 scripts/build_menu.py ~/Downloads/menu_images menu.csv
```
Скрипт читает `menu.csv`, у фото напитков на белом фоне вырезает фон (прозрачный WebP), сжимает все фото до 520×416 и миниатюр 280×224 и перезаписывает `menu.json`.

## Структура
`index.html` · `style.css` (цвета, неон и тайминги в `:root`) · `main.js` · `menu.json` · `assets/menu/*.webp` · `assets/logo-*.webp` · `favicon.svg`

## Логотип
Фирменный логотип (белая надпись с розовым контуром) вырезан со стакана на фото. `scripts/build_logo.py` рисует из него две готовые картинки: погашенная вывеска (`logo-dim.webp`) и включённая со свечением (`logo-lit.webp`). Если появится логотип в SVG или PNG с прозрачным фоном, замените эти два файла: в браузере анимируется только прозрачность слоя.

## Производительность
- Свечение логотипа, зерно и виньетка запечены в картинки, тяжёлых CSS-фильтров на анимируемых элементах нет.
- Анимации секций вне экрана ставятся на паузу; курсор-шлейф на лёгких DOM-точках и считается только пока мышь двигается.
- Если устройство слабое (1–2 ядра, мало памяти, `prefers-reduced-motion`) или кадры идут медленно, сайт сам включает упрощённый режим. Принудительно: `?fx=lite` или `?fx=full` в адресе.
